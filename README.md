# Portfolio de Manuel Molina

Sitio personal de Manuel Molina, IT Monitoring Operator en Buenos Aires.

**IT Monitoring Operator | Command Center | IT Operations**

## Qué muestra

- **Circuito de trabajo:** monitorear, detectar, registrar, notificar, escalar y dar seguimiento.
- **Simulación de alertas:** cuatro alertas ficticias con el paso a paso de cómo se gestionan y un ticket de ejemplo. No es un sistema de monitoreo real.
- **Experiencia laboral:** Sanatorio Otamendi, Medicus, Sondeos Global, Beretta Galarce & Asociados y Claro Argentina.
- **Habilidades:** solo herramientas usadas profesionalmente. La formación en curso figura aparte.
- **Laboratorios:** seis prácticas de monitoreo planificadas, que se publicarán en GitHub a medida que estén terminadas.
- **Contacto:** formulario y enlaces a LinkedIn y GitHub.

## Estructura

| Archivo | Contenido |
| --- | --- |
| `index.html` | Estructura y textos del sitio |
| `style.css` | Estilos, tema oscuro y claro, adaptación a móvil |
| `script.js` | Cambio de tema, menú, simulación de alertas y formulario |

Es un sitio estático, sin dependencias ni paso de compilación. Las tipografías (IBM Plex Sans e IBM Plex Mono) se cargan desde Google Fonts.

## Cómo verlo en tu computadora

Abrí `index.html` en el navegador, o levantá un servidor local:

```bash
python3 -m http.server 8000
```

y entrá a `http://localhost:8000`.

## Publicación

El sitio se puede publicar con GitHub Pages desde la rama `main`, carpeta raíz.

## Formulario de contacto

El formulario envía los mensajes a través de Formspree. El destino está en el atributo `data-endpoint` del formulario, en `index.html`.
